DOM VIRUS 0.46 marks Battlefield Blitz as playable and names the shared engine: Fizlet. DOM VIRUS is the hub for tiny open-source arcade games that play on the page you are reading. Pick a cartridge, play, and hit Recall to give the page back.

[text]
heading: What's new for players

Battlefield Blitz is out. The coming-soon page now marks it PLAYABLE with a Play it now key, and the DOM Battlefield page links to it. Blitz lives on the DOM Battlefield site.

The release before this one, 0.45, opened the coming-soon page: the next games in build order and the next engine phase. It also added the DOM Kaiju details page and a COMING SOON cartridge on the shelf.
[/text]

[text]
heading: For developers

The engine has a name and a release: Fizlet 0.2, a kernel plus input, collide, fx, sound and embed bricks. The engine plan logs phase E1 as done and E2 as started.

The hub ships site kit 1.49.0. The four embedded games still run on the shared DOM VIRUS runtime; moving them onto Fizlet is the next phase.
[/text]
