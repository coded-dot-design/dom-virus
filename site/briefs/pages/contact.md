The quickest way to reach DOM VIRUS is GitHub. Report bugs and share ideas in the issues, send security reports privately, and find facts and logos in the press kit. An email address is coming soon.

[cta]
Open a DOM VIRUS issue -> https://github.com/coded-dot-design/dom-virus/issues
[/cta]

[faq]
Q: Is there a contact form?
A: Not yet. A form needs a server, and the site is static for now. Until then, GitHub issues reach us fastest.
Q: Do I need a GitHub account?
A: Yes, to open an issue or send a security report. A GitHub account is free.
Q: Where do I report a security problem?
A: Use GitHub's private vulnerability reporting on the DOM VIRUS repository. Only the maintainer can read it, so please keep it out of public issues.
Q: When will there be an email address?
A: Soon. It will appear on this page and in the press kit as soon as it is set up.
[/faq]
